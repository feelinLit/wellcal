# Подшивалов О. И. M33061

Приложение для учета приемов пищи с калькулятором БЖУ

__Figma__:  
https://www.figma.com/file/QAwCMx3WIyVQ0mx33ZQBdB/wellcal-project-web?node-id=0%3A1

### Entities:
1. __User__ -- пользователь зарегистрировавшийся в приложении.
2. __Person__ -- человек, описывающийся его ростом, весом, возрастом, полом и уровнем активности, на основе которых строится `Plan`.
3. __Food__ -- продукт(огурец, голень курицы, борщ), который описывается названием и БЖУ.
4. __Meal__ -- прием пищи, который состоит из 1.\.* `Food`.
5. __Day__ -- день, состоящий из 0\.\.* `Meal`
6. __Plan__ -- персональный план дневного БЖУ, ассоциированный с одним `User`.
